# Content Website Requirements

## Vision

Build a production-ready technical publication focused on: - Open Source
AI - Consumer & Enterprise Hardware - Long-term Investing (ETFs, passive
investing, financial education)

Primary goals: 1. Create a live production website. 2. Demonstrate
full-stack engineering skills. 3. Build a portfolio project for
interviews. 4. Publish content you genuinely enjoy reading. 5. Add
monetization later without redesigning the platform.
